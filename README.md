# commander-goldfish

統率者戦（4人戦）のデッキを一人回し（ゴールドフィッシュ）で練習する PWA。
対戦相手3人のライフ（40）と統率者ダメージだけを数え、妨害は編集モードで手動で再現する。

デッキは上部の「デッキ」で切り替えられる（いまは イングリス・スティンガークイル（黒赤・トークン×1点バーン×ダメージ増幅）の1つ）。
URL に `?deck=<id>` を付けると、そのデッキで開く。選んだデッキは次に開いたときも使われ、記録もデッキごとに分かれる。

- PC：ブラウザで開く
- Android：Chrome で開き「ホーム画面に追加」。一度開けばオフラインでも動く

新しいバージョンは自動で入る。アプリを開いたとき・前面に戻ったとき・開いている間は1時間ごとに確かめ、
対局を始める前か終わったあとならその場で、対局中なら次のゲームを始めるときに更新する（すぐ更新するボタンも出る）。

## 遊び方

| 操作 | やり方 |
|---|---|
| 土地をプレイ・呪文を唱える | 手札のカードを上（戦場）へドラッグ。カードを押すと詳細が開き、そこからも選べる |
| マナ | 唱えるときに未タップの土地・マナ石から自動で払う。手動でタップするときはカード詳細の「マナ」 |
| 攻撃 | 「戦闘へ」→ クリーチャーを対戦相手へドラッグ（または「全員で 相手N」）→「N体で攻撃」→「戦闘ダメージ」→「戦闘終了」。ダメージのあと戦闘終了までは攻撃中の扱いで、インスタントで生け贄にできる（ガルナで引ける） |
| 起動型能力 | カード詳細のボタン |
| 選択（生け贄・対象・X など） | 画面中央に出る問い合わせに答える。「やめる」（または Esc）でその操作の前に戻る。選択が続くときは「1つ戻す」で前の選択へ |
| 元に戻す | 上部のボタン、または Ctrl+Z / Ctrl+Y |
| カードの詳細 | カードを押す（右クリック・長押しでも開く） |
| 閉じる | Esc、または背景を押す |

光っているカードは、いまプレイ・唱える・起動・攻撃ができるもの。

### 編集モード

上部の「編集モード」で入る。ルールの制約を外して、相手からの妨害などを手で再現する。

- どの領域のどのカードでも、ドラッグかカード詳細から任意の領域へ移せる
  （手札・戦場・墓地・追放・統率領域・ライブラリーの上/下/シャッフルして入れる）
- 効果なしのタップ/アンタップ、カウンターの増減
- トークンの作成、全クリーチャー破壊、シャッフル
- 自分と相手のライフ、統率者ダメージ、スピード、統治者、マナ・プールの直接編集
- 「移動で誘発させる」にチェックを入れると、移動で ETB や死亡の誘発が起きる（既定は起きない）

### 記録

「記録」に、ターンごとのダメージ（相手別）、発生源ごとの合計、これまでのキルターンが出る。
URL に `?seed=123` を付けると同じ初手・同じドロー順で遊べる。

## 自動処理の範囲

ルールの土台（ターン進行・ドロー・マナ・統率者税・統率者ダメージ・脱落・手札上限）は自動。
カードの効果は、デッキの軸になるものだけを `src/cards/scripts/` に書いてある
（展開時/攻撃時のバーン、トークン生成、ダメージ増幅、生け贄ドロー、タップインの条件など）。
書いていないカードは効果テキストを表示するだけなので、編集モードで処理する。
カード詳細とデッキ一覧に「自動処理あり」かどうかが出る。

カード詳細の効果・タイプ行は日本語（`decks/<id>/ja.json`）で、その下に使い方のコツが出る。
カード画像は Scryfall の日本語版（無いカードだけ英語版。取り込み時に名前が出る）。

## デッキの追加・差し替え

デッキは `decks/<id>/`（カードの一覧・日本語の文章とコツ）に置き、`npm run import-deck` で取り込む。
**新しいデッキの追加手順は [docs/adding-a-deck.md](docs/adding-a-deck.md)。** アプリのコードを書き換える必要はない。

```bash
npm run new-deck -- <id> "<表示名>" "<統率者の英語名>"   # 雛形を作る
npm run import-deck -- <id>                               # 取り込む（引数なしなら全デッキ）
```

既存デッキのカードを入れ替えるときは `decks/<id>/` の CSV を直して取り込み直す。
新しいカードはスクリプトが無くても手動扱いですぐ使える。

## 開発

開発のルール（構成・エンジンの約束・カードの足し方・テストの書き方・コミット）は [CONTRIBUTING.md](CONTRIBUTING.md) にまとめてある。

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # ユニットテスト（vitest）
npm run test:e2e     # e2e（Playwright）。e2e だけで src/ のカバレッジ 100% を要求する
npm run build        # dist/ に PWA を出力
```

初回の e2e の前に `npx playwright install chromium` が要る。

main に push すると GitHub Actions がテストを通したうえで GitHub Pages に配信する。

カード画像とデータは [Scryfall](https://scryfall.com/) のものを使っている。
