# 相手ありモード

一人回しに「おおよそ想定される相手の盤面」を足し、ブロックされる前提で攻撃先・除去・生け贄の判断を練習するためのモード。
遊び方は [README](../README.md#相手ありモード)、守るべき実装の約束は [CONTRIBUTING 4.7 節](../CONTRIBUTING.md#47-相手ありモードの約束) にある。
ここは仕組みと、段階的に足していく計画をまとめる。

## 決めたこと（2026-10-02 本人の回答）

| 論点 | 決定 |
|---|---|
| 盤面の作り方 | **積み上げ**。相手のターンごとに前の盤面へ足していく（倒したブロッカーは戻らない）。編集モードに「作り直す」を置き、その時点で想定される盤面をいつでも引き直せる |
| 最初の版の範囲 | **盤面・ブロック・こちらの除去まで**（第1段階）。相手はあなたを攻撃せず、除去もしない |
| 相手の攻撃で止まる頻度（第3段階で使う） | **攻撃されるたび**に止まり、「おすすめでブロック／自分で選ぶ／ブロックしない」を選ぶ。1巡で最大3回止まる |
| 相手の強さ | **席順をシードで決める**（1〜4番手）。性格（アグロ・ミッドレンジ・コントロール・トークン）もシードで引く。`?seat=1..4` で席を固定できる |

## 相手のモデル

- 相手の盤面は `Opponent.board`（`RivalPermanent`：種類・タップ・召喚酔い・受けたダメージ）。**`CardInstance` にしない。**
  `creatures(s)` や `battlefield(s)` を見る既存のスクリプト（宮廷の X、ステンシアの13個、展開時の誘発）が相手側に反応しないようにするため
- 種類は汎用の架空クリーチャー14種（兵士トークンを含む）＋性格ごとの統率者（`src/engine/rivals/kinds.ts`）。能力は Scryfall と同じ英語のキーワード名で持ち、
  ルールの判定には自分側と同じ考え方を使う。画面に出すときは `KEYWORD_JA` を通す
- 相手は土地・マナ・手札・墓地を持たない。相手どうしのライフの削り合いもしない（キルターンを一人回しと比べられるように、相手のライフはあなたが削った分だけ減る）
- 相手が脱落したら、その相手の盤面はゲームから除く（死亡ではないので何も誘発しないが、エレジーの見習いの虚空の「土地以外のパーマネントが戦場を離れた」には数える）

### 性格と育ち方

| 性格 | 重み | 展開（相手の1〜6ターン目の期待値） | よそを攻撃してタップする率 | 統率者（登場ターン） |
|---|---|---|---|---|
| アグロ | 20 | 0.6 / 1.0 / 1.2 / 1.0 / 1.0 / 1.0 | 70% | 3/3 トランプル（3） |
| ミッドレンジ | 40 | 0 / 0.6 / 0.8 / 0.9 / 0.9 / 0.9 | 45% | 4/4 飛行（4） |
| コントロール | 20 | 0 / 0.2 / 0.3 / 0.4 / 0.4 / 0.5 | 25% | 2/5 飛行（5） |
| トークン | 20 | 兵士 0 / 1 / 1 / 2 / 2 / 2 | 55% | 3/3（4） |

相手の1ターン（`rivalStep`）：アンタップ → 消耗（ほかの卓の戦いで倒れることの近似。8%、兵士は12%）→ 展開（使えるマナ＝ターン数に近い種類ほど出やすい）
→ 統率者（登場ターンに達し、戦場にいなければ）→ よそを攻撃してタップ（召喚酔い・防衛は除く）→ 要約とログ → クリンナップ。1人8体まで（編集で出すときも8体まで）。

### 席順

- あなたの席（1〜4番手）はシードで決まる。対戦相手1・2・3はあなたの次の席から順に並ぶ
- あなたより前の席の相手は、キープのあと、あなたの1ターン目より前に1ターン進む（`preRound`）
- あなたのクリンナップのあと、相手1→2→3が1ターンずつ進んでから、あなたの次のターンが始まる（`nextTurn` → `rivalRound`）。
  手札上限で捨てる選択をしたあとも同じ経路を通る

### 乱数

- 相手の乱数は `rivals.rng`（シードから作った別の流れ）。配りの `rng` には触れないので、**相手あり／なしで初手とライブラリーの順は同じ**
- 対局の開始時に4個（席1・性格3）、相手の1ターンにつき**必ず32個**引く（脱落していても、使わない分も）。使い道は添字で予約してある（`kinds.ts` の `ROLL`）

| 添字 | 使い道 | 段階 |
|---|---|---|
| 0〜7 | i 番目のクリーチャーの消耗 | 1 |
| 8〜15 | i 番目のクリーチャーがよそを攻撃するか | 1 |
| 16 | 展開する数 | 1 |
| 17〜19 | 展開する種類 | 1 |
| 20 | あなたを攻撃するか | 3 |
| 21 | 統治者を持つときの追加の展開 | 3 |
| 22〜25 | 相手からの干渉 | 4 |
| 26〜31 | 予備 | — |

  こうしておくと、自分の回し方を変えても（相手のクリーチャーを倒しても）相手の乱数の流れはずれない。同じシードで別の回し方を比べ直せる
- 作り直しは `rivals.rng` を使わず、（シード・相手・ターン数・作り直しの回数）から作った乱数で行う。本来の流れをずらさない
- 表の数値を変えると、同じシードでも相手の盤面は変わる（配りは変わらない）

## 戦闘

| フェイズ | 相手あり |
|---|---|
| 攻撃宣言 | 攻撃時の誘発（イングリスの1点など）を先に解決する |
| `declared`（ブロックの前） | インスタントか起動型能力を使えて、ブロックできる相手のクリーチャーがいるときだけ止まる。除去でブロッカーを消せば、その攻撃は通る |
| `attacking`（ブロックの後） | 相手のブロックが見える。ブロックされたトークンを生け贄にすれば、攻撃中なのでガルナで引ける |

### 相手のブロック（`assignBlocks`）

- アンタップの相手のクリーチャーが、1体につき1体の攻撃を止める（召喚酔いでも止める）。飛行は飛行か到達でしか止めない。
  **威迫は止めない**（相手は2体でブロックしない。ルール違反ではなく単純にしているだけ）
- 攻撃クリーチャーを価値の大きい順に見て、①生き残って倒せる → ②生き残る → ③相討ち（攻撃側の価値がブロッカー以上のとき。アグロはしない）→ ④止めない。
  判断には**増幅込みの点**を使う（トーブランがいると、熊は赤いゴブリンと相討ちになるので止めない）
- 価値：あなたのトークンは0、それ以外はマナ総量＋5（増幅か誘発を持つ）＋10（統率者）。相手のクリーチャーはマナ総量、統率者は10
- 最後に、ブロックされない攻撃で致死（ライフか、統率者ダメージ21）なら、残りで点の大きい攻撃から価値の小さいブロッカーでチャンプブロックする

### ダメージ

- 割り当ては基本のパワーで行う（CR 702.19）。トランプルはブロッカーに致死量（残りのタフネス、接死なら1）を割り当て、残りを本体へ
- 増幅は受け手ごとに1回だけ足す（相手のクリーチャーへは `damageRival`、プレイヤーへは `damageOpponent`）。
  例：トーブランがいて、稲妻の憤怒獣 5/1 トランプルが熊 2/2 に止められたら、熊に 2+2=4点、本体に 3+2=5点
- ブロッカーがダメージの前に除去されても、攻撃クリーチャーはブロックされたまま（トランプルなら全点が本体へ、そうでなければ0）
- 相手の絆魂（天使）は、その相手のライフを増やす。あなたの絆魂（エレジーの見習い・エレボスの鞭）はブロッカーへのダメージにも乗る
- 戦闘ダメージは同時なので、死亡と脱落は全員分を割り当ててからまとめて処理する（ガルナは同時に死んだクリーチャーも見届ける。相手のクリーチャーの死亡を先に処理するので、同時に死ぬ病的な日和見主義者も引ける）。
  途中で相手のライフが0になっても、その相手にブロックされている戦闘はそのまま行われる
- エレジーの見習い・顔壊しのプロ・ギックスの「戦闘ダメージを与えたとき」は、相手のライフの増減ではなく与えた点数で見る（相手の天使の絆魂で相殺されても誘発する）
- 蘇生・エレボスの鞭で戻したクリーチャーは、戦闘で死ぬときも追放される（死亡しないので、ガルナ・病的な日和見主義者は誘発しない）
- 相手のクリーチャーが受けたダメージは、どのターンのクリンナップでも消える（CR 514.2）

### 相手のクリーチャーの死亡（`destroyRival`）

このターンに死亡した数（ラゴモス）と、土地以外が戦場を離れたこと（エレジーの見習いの虚空）に数え、`onRivalCreatureDies`（病的な日和見主義者）を呼ぶ。
ガルナは「あなたがコントロールしている」クリーチャーにしか反応しないので呼ばない。相手のターンの始めに `flags` を新しくするので、
病的な日和見主義者は相手のターンにも1回ずつ引ける。統率者が離れたら、出し直しが1ターンずつ遅れる（統率者税の近似）。

## カードへの影響（第1段階）

| カード | 相手ありで変わること |
|---|---|
| 冥府の掌握・萎縮させる責め苦・苦々しい勝利・大群への給餌 | 唱えるときに対象を選ぶ（相手のクリーチャーはチップ、自分のカードは絵）。適正な対象が無ければ唱えられない。相手なしでは今までどおり手動 |
| 冒涜の行動 | 相手のクリーチャーも数えて軽くなり、相手の盤面も流す |
| トーブラン・機械化戦・巡り合わせたる火の力・ファー・フォーチュン | 相手のクリーチャーへのダメージにも乗る（`damageBonus` の `to`） |
| 病的な日和見主義者 | 相手のクリーチャーの死亡でも引く |
| 不穏な火道 | クリーチャー化で威迫（`animated.keywords`）。相手は止めない |
| フライヤ | 跳躍：自分のターンは飛行 |

コツ（`decks/ingris/ja.json`）は「相手ありモードでは〜」と書き分けてある。

## 近似していること

- 消耗とよそへの攻撃は抽象化している。相手は2体でブロックしない。統率者税は出し直しの遅れで近似
- ブロックの前の窓は、応答手段とブロッカーがあるときだけ1タップ増える
- 相手は決まった規則で動くので、慣れると読める。読み合いではなく、自分の判断の練習のためのもの
- 表の数値は経験則。遊んでから調整する（調整するとユニットテストの分布の期待値も変わる）

### 第3段階のメモ（決めてあること）

- 相手の1ターンの手順5で、`rolls[20]` が「あなたを攻撃する率」未満ならあなたを攻撃する。率は性格ごと（アグロ50%・ミッドレンジ30%・コントロール15%・トークン35%）に、
  あなたが統治者なら+50%、アンタップのブロッカーがいなければ+15%（上限95%）
- 攻撃に出すのは、アンタップ・召喚酔いでない・防衛でない・あなたのブロッカーと1対1で割り当てても倒されないもの。あなたが統治者なら、アグロは全員で来る
- **攻撃されるたびに止まる**（本人の選択）。おすすめは `assignBlocks` をあなたの側に当てたものに、ガルナ（攻撃していないトークンが死ぬと各相手に1点）と統治者を守ることを足して決める
- 止まっている間はインスタントと起動型能力を使える。「やめる」は止まった状態まで戻す
