# RADカウンター・切削・カウンター・増殖

賢きモスマンのデッキ（`decks/mothman/`）のために足した仕組み。ほかのデッキのカードにも同じ仕組みが効く。
2026-10-03 に本人が「主要な処理まで自動化する（最初のメイン・フェイズの切削、賢きモスマンのカウンター配り、増殖）」を選んだ。

## 状態

| 項目 | 持ち方 |
|---|---|
| あなたのRADカウンター | `GameState.rad` |
| 対戦相手のRADカウンター | `Opponent.rad` |
| 対戦相手のライブラリー | `Opponent.library`（枚数だけ。最初は92枚＝99枚から初手7枚）。中身は持たない |
| 対戦相手の墓地 | `Opponent.graveyard`（切削された枚数）と `Opponent.milled`（土地でないカードの近似に使う累計） |
| ライブラリー切れ | `Opponent.decked`。ライブラリーが0枚のときに引こうとすると敗北する（CR 704.5b） |
| このターンに対戦相手が失ったライフ | `TurnFlags.oppLifeLost`（血の長の昇天） |
| このターンに唱えた呪文の数 | `TurnFlags.spellsCast`（ラッドストームのストーム） |
| 「毎ターン1回」の誘発 | `TurnFlags.onceUsed` と `once(s, key)`（core.ts） |

## 対戦相手のターン（相手なしモードでも起こす）

あなたのクリンナップのあと、対戦相手1→2→3が1ターンずつ進む（`engine/opponents.ts`）。

1. ターンの始め：`flags` を新しくする（1ターンに1回の誘発が戻る）。1枚引く（ライブラリーが無ければ敗北）。
   **最初のメイン・フェイズのRADカウンター**（下記）
2. （相手ありモードだけ）盤面が育つ（`rivals/index.ts` の `rivalStep`）
3. ターンの終わり：各終了ステップの誘発（`onEachEndStep`。血の長の昇天）とクリンナップ

3つに分けて積むので、始めの切削で誘発したもの（賢きモスマンなど）は、盤面の動きと終了ステップより前に解決する。
相手は呪文を唱えず、攻撃もしない（相手ありモードの第3段階まで）。

## RADカウンター（CR 728.1）

各プレイヤーの最初のメイン・フェイズの開始時に、RADカウンターの数だけ切削し、土地でないカード1枚につき1点のライフを失い、RADカウンターを1個取り除く（取り除けるのは持っている数まで）。

- あなた：`startTurn` のドローのあとに `radYou`。ライブラリーは実物なので、何が落ちたかもそのまま
- 対戦相手：`opponentTurnStart` で `radOpponent`。失ったライフはダメージの記録（ターンごとのグラフ）に「RADカウンター」として入る

## 対戦相手の切削の近似

対戦相手のライブラリーは中身を持たないので、切削したカードのうち土地でないものを**5枚に3枚**とみなす。
乱数は使わず、それまでに切削された枚数の累計 m から、土地でないカードを `floor(3m/5)` 枚と数える
（1枚目は土地・2枚目は土地でない・3枚目は土地・4枚目と5枚目は土地でない、を繰り返す）。同じ操作なら同じ結果になり、長く見ると割合がちょうど 3/5 になる。

## 切削の誘発

`millYou(s, n)`（あなた）と `millOpponents(s, opps, n)`（対戦相手たち。同時の1回）が、カードスクリプトの `onMilled` を呼ぶ。
同時に切削したものはまとめて1回で、賢きモスマンは1回だけ誘発し、X はその合計（公式の裁定どおり）。
墓地にあるカードには `onMilledInGraveyard`（群生するラッドローチ）。水のクリスタルがあると、対戦相手の切削は1人ごとに4枚増える。

## カウンター

- **置く**：`addCounters(s, card, kind, n)`。置換は、足すもの（硬化した鱗・巻きつき蛇・囁かれる希望の神）を先に、倍にするもの（屍体屋の脅威・枝分かれの進化）を後に適用する。
  置換の順は影響を受けるもののコントローラーが選べる（CR 616.1）ので、いちばん多くなる順にしている。置いたあと `onCountersPut` を呼ぶ
- **RADカウンターを得る**：`youGetRad` / `oppGetsRad` / `radEach`。あなたが得るときは巻きつき蛇で1個多い
- **増殖**：`proliferate`。**対戦相手全員のRADカウンターと、あなたのパーマネントのカウンターを1種類につき1個ずつ増やす。あなたのRADカウンターは増やさない**
  （自分の切削を増やしたいときは編集モードで足す）。選ぶ手間を省くための決め方

## ライフの喪失

- 対戦相手：`oppLoseLife`（ダメージではない喪失）と `damageOpponent`（ダメージ）が、どちらも `onOpponentLosesLife`（精神クランク・湖の町の統領）を呼ぶ
- あなた：`youLoseLife`（支払いを含む）が `onYouLoseLife`（湖の町の統領）を呼ぶ。**あなたのライフを減らすときは `s.life -=` ではなく `youLoseLife` を通す**

## 自動で処理するカード

| 種類 | カード |
|---|---|
| 統率者 | 賢きモスマン（出たとき・攻撃したとき全員にRAD、切削でカウンターを配る。クリーチャーが X 体以下なら全員に、多いときだけ選ぶ） |
| RADを与える | 金切り声のスコーチビースト・放射性降下物・光る輩・群生するラッドローチ・フェラル・グール・マイアラーク・クイーン・厄介なラッドガル・テイト農夫（聞く）・マリポーサ軍事基地（聞く） |
| 増殖 | かき鳴らし鳥・流束の媒介者・進化の賢者・カーンの拠点・実験的占い・原子化・変異の賜物（増殖だけ）・ラッドストーム |
| カウンターの置換 | 硬化した鱗・巻きつき蛇・囁かれる希望の神・屍体屋の脅威・枝分かれの進化 |
| 切削 | 縫い師への供給者・事件現場の分析者・六番（攻撃時）・思考掃き・遺跡ガニ・群の祭壇・生垣裁断機（土地を戦場へ）・水のクリスタル |
| 勝ち筋 | 血の長の昇天・精神クランク・湖の町の統領 |
| 受け皿 | 水深の魔道士・沈思の教授・海中の戦士、レイ・フィレット・狩りの仕込み・日を浴びる繁殖鱗・進化の証人・惑星共生・古代の災厄、ジェノバ・搭載歩行機械・培養ドルイド・鼓舞する呼び声（引く枚数だけ） |
| 除去（相手ありモード） | 喉首狙い・暗殺者の戦利品・内にいる獣・原子化 |

「〜してもよい」で損にならないもの（ドロー・トークン・探索カウンター・血の長の昇天の2点）は自動で行う。
スコーチビーストのトークンと惑星共生のドローは、そのターン最初の機会に行う（本来は見送って後の大きい機会を待てる）。

## 手動のまま（編集モードで処理する）

墓場波、ムルドローサ・六番の回顧（墓地から唱える）、催眠の宝珠、サテュロスの道探し、テイト農夫とマリポーサ軍事基地の起動型能力、
量子の謎かけ屋、速足のブーツ、タミヨウの保管、湖での水難、対抗呪文、変異の賜物と鼓舞する呼び声の破壊不能など、
ジェノバでミュータントになる効果、生垣裁断機の搭乗、血の長の昇天の「相手が唱えた呪文で墓地に置かれたカード」。

## テスト

`tests/e2e/rad.spec.ts`（仕組み）と `tests/e2e/mothman-cards.spec.ts`（カード）。
ライブラリーの上を `app.put(name, 'library')` で並べてから切削させると、何が落ちるかを決められる。
対戦相手の切削は上の近似で数えるので、期待値は累計の枚数から計算する。
